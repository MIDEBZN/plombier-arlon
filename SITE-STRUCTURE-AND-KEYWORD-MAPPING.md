## Synthèse d'Implémentation Technique

1. **Maillage Interne** : Toutes les pages secondaires renvoient vers la page d'accueil avec l'ancre `plombier Arlon`, et la page d'accueil liste et contextualise les 7 services via des cartes dédiées.
2. **Schema Markup** :
   * Chaque page Service intègre un Schema `Service` avec `provider` pointant vers l'entité `@id` de la société.
   * La page d'accueil et la page Contact intègrent le Schema `Plumber` complet avec les coordonnées GPS d'Arlon.
3. **Core Web Vitals** : Garder le DOM ultra-léger (< 1 500 nœuds), convertir les images en WebP et différer tous les scripts non critiques pour garantir un LCP < 1,2 seconde sur mobile.
